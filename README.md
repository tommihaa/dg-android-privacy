# dg-android-privacy

DG Androidin tietosuojaseloste julkisessa osoitteessa: <https://tommihaa.github.io/dg-android-privacy/>.

Play-kauppa vaatii selosteen julkisesta osoitteesta. Sovelluksen oma repo on yksityinen,
eikä sitä avata tämän takia, joten seloste asuu tässä erillisessä repossa. Selosteen
lähde ja perustelut sille mitä siinä sanotaan ja mitä ei ovat sovelluksen repossa
(`docs/TIETOSUOJA.md`); tämä repo on vain julkaisupinta.

Yksi sivu, käsin kirjoitettu `index.html`. Ei buildia, ei JavaScriptiä eikä ulkoisia
pyyntöjä. `.nojekyll` estää Jekyll-käsittelyn.

**Julkaisu:** push `master`-branchiin. GitHub Pages palvelee juurta suoraan.
